# 方块坠落

一个为安卓手机和微信内置浏览器优化的单文件俄罗斯方块小游戏。

线上地址：<https://p18920089088-coder.github.io/block-shift-game/>

## 直接打开

用浏览器打开 `index.html` 即可，不需要安装依赖或启动服务器。

## 触控

- 左移 / 右移：按住可连续移动
- 旋转：顺时针旋转
- 下移：按住可连续软降
- 落下：直接落底
- 暂存：保存当前方块

## 键盘

- `←` `→`：移动
- `↑` / `X` / `Z`：旋转
- `↓`：软降
- `Space`：直接落底
- `C` / `Shift`：暂存
- `P` / `Esc`：暂停
